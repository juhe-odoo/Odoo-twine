# How to contribute

1. Download Twine (https://twinery.org/) (Flatpak for Linux: https://flathub.org/en/apps/org.twinery.Twine)
2. Clone this repository into ~/Documents/Twine/Stories/
3. Open Twine
4. Open the "index" project

## If you don't want to make the changes yourself:

1. Open an issue describing the change or addition you want to make https://github.com/juhe-odoo/Odoo-twine/issues
2. I suggest using another tool like https://excalidraw.com/ to outline the flowchart. This makes it easier to translate into Twine.
